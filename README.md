# Quality Scope Manufacturing Analytics

## 📌 Executive Summary
This project focuses on quality control analysis and operational optimization within a manufacturing pipeline. By evaluating production logs, defect rates, machine sensor metrics, and quality inspection parameters, this project identifies critical defect drivers and proposes data-driven quality control strategies.

---

## 🛠️ Tech Stack & Tools
* **Language:** Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
* **Environment:** Google Colab / Jupyter Notebooks
* **SQL & Database Management:** Querying production & quality metrics
* **Visualization / BI:** Tableau / PowerBI / Seaborn

---

## 🔑 Key Objectives & Analysis
1. **Defect Rate & Scrap Reduction:** Analyzed manufacturing inspection records to identify high-variance production lines and root causes of component defect spikes.
2. **Quality Control & Tolerance Monitoring:** Evaluated batch-wise sensor readings and operational thresholds to identify process anomalies.
3. **Yield Optimization:** Formulated statistical insights to stabilize product yield and minimize material waste during batch processing.

---

## 📊 Business Impact & Key Recommendations
* **Targeted Quality Audits:** Identified specific machine shifts and parameters associated with peak defect rates.
* **Process Calibration:** Recommended tighter tolerance bounds for key sensor parameters to prevent defect cascading across downstream assembly lines.
* **Cost Reduction:** Highlighted potential material cost savings by reducing batch rework and scrap rates.
